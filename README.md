# Racha — Divisão por Estrelas

Site estático para sortear times de futebol a partir de uma lista de jogadores agrupados por estrelas.

## Publicar gratuitamente com GitHub Pages

1. No GitHub, crie um repositório novo chamado `racha-divisao-por-estrelas`.
2. Deixe o repositório como **Public**.
3. Envie todos os arquivos e pastas deste projeto, mantendo a estrutura:

   ```text
   index.html
   README.md
   assets/racha-logo.png
   ```

4. No repositório, abra **Settings → Pages**.
5. Em **Build and deployment**, escolha **Deploy from a branch**.
6. Selecione a branch `main` e a pasta `/ (root)`; clique em **Save**.
7. Aguarde a publicação. O GitHub exibirá o endereço do site na própria tela de Pages.

## Como usar

Cole a lista no formato `5 estrela`, nomes (um por linha), depois `4 estrela` e assim sucessivamente até `1 estrela`. Clique em **Sortear times**.

## Privacidade e funcionamento

O sorteio é executado localmente no navegador. O site não possui backend, banco de dados, cadastro ou envio dos nomes para um servidor próprio. O GitHub Pages hospeda os arquivos estáticos do site.
